# Hello World Python GUI

A simple GUI application built with Python and Tkinter.

## Requirements

- Python 3.7+
- tkinter (system dependency)

## Installation

**Ubuntu/Debian:**
```bash
sudo apt-get install python3-tk
```

**macOS:**
```bash
brew install python-tk
```

**Windows:**
tkinter is included with Python by default.

## Running

```bash
python main.py
```
